2. yang akan terjadi (di browser) kalau kamu klik tombol "Simpan" tanpa mengisi field "Nama"? Coba buka filenya di browser dan praktikkan.
    akan muncul peringatan "please fill out this field" itu berlaku juga untuk pengarang, tahun tertit dan stok, karena di kode input ada requiref
